PlantEvo-Viewer : Evolution des végétaux, de l'eau à la terre.

DESCRIPTION 
PlantEvo-Viewer est un projet instructif et numérique de concession de page web réalisé dans JavaScript à partir d'une marquette conçu dans Figma et exécuté dansle navigareur. PlantEvo vise à rendre l’histoire et l’évolution du monde végétal compréhensible, visuelles et accessibles à tous.

TECHNOLOGIES UTILISEES    
Pour ce projet, nous avaons utilisé :
- JavaScript pour éditer les lignes de code HTML et CSS,
- Un live Server de Vs-Code pour voir le rendu de notre travail,
- FIGMA pour la concession de la marquette de notre page web,
- Kobo qui est un application de collecte de données,
- GitHub pour deversser et collaborer sur le projet
- QGIS, le logiciel qui nous a permis de réaliser la carte de localisation des différents groupes végétaux.

OBJECTIF    
L'objectif de ce PlantEvo-Viewer est de concevoir une plateforme numérique interactive permettant de comprendre et de visualiser l'évolution du monde végétal de manière simple, attractive et accessible à tous.

LIMITE
- Il y a certaines images telle que l'appareil reproducteur et végétatif des algues et des mousses qui n'ont pas été illustrées
- sur le site web on ne peux savoir en combien de temps les différents groupes ont reussi à mettre en place les différentes inovation observées.

DEROULEMENT    
Le projet suit la logique suivante :
- Documentation sur les des différents groupes végétaux et leur chronologie ;
- Création de la marquette de la plateforme web dans FIGMA ;
- Devéloppement de l'interface à partir du Html et du CSS ;
- Test des différentes fonctionnalités et amélioration du site web. 

FONCTIONNALITES PRINCIPALES
le site web propose trois option principales :
- On a la fonction Accueil qui présente de façon générale PlantEvo et c'est quoi l'intérêt de ce projet
- La fonctionnalité Les groupes, c'est l'option qui nous permet de découvrir les 06 grands groupes végétaux
- Et la fonctionnalité Description. Dans cette option chauqe groupes est présenté et decrit avec ses différents caratéristiques.
NB : il y a la possibilité de cliquer sur chaque groupe dans la fonctionnalité LES GROUPES afin d'avoir uniquement les informations de ce groupe de façon spécifique.
